TPV Barra

Punto de venta táctil para cobrar tickets de bebida en barras de eventos y festivales

Proyecto finalizado
Web JavaScript Mobile First Herramienta
Ver en GitHub Pages

Herramienta desarrollada para uso propio como cajera en la barra de un festival, donde necesitaba cobrar rápido tres tipos de ticket de bebida y calcular el cambio sin margen de error. Un caso real, pensado y probado para funcionar bajo presión, con muchos clientes seguidos y poco tiempo entre cada cobro.

Sobre el proyecto

TPV Barra es una pequeña aplicación web pensada como punto de venta táctil para la gestión de cobros en la barra de un evento. Permite llevar la cuenta de tres tipos de ticket (combinado, cerveza/refresco y agua), sumar el total automáticamente y calcular el cambio exacto a partir del dinero que entrega el cliente.

Está construida en HTML, CSS y JavaScript vanilla, sin frameworks ni dependencias, para que cargue al instante y funcione de forma fiable en Safari sobre iPhone, el dispositivo real con el que se usa en la barra. Los precios de cada ticket son configurables y se guardan en el propio dispositivo, así que solo hace falta ajustarlos una vez antes del evento.

El diseño prioriza botones grandes para el pulgar, alto contraste para verse bien al sol, y un flujo de trabajo mínimo: sumar tickets, teclear el pago, leer el cambio y limpiar para el siguiente cliente.

Matemáticas exactas: todo se calcula en céntimos

El punto más delicado de un TPV es el cambio: un error de redondeo con decimales puede hacer que la cuenta no cuadre. Por eso todo el dinero se maneja internamente como números enteros de céntimos en lugar de decimales, evitando los típicos fallos de coma flotante de JavaScript.

  • Precios y subtotales en céntimos enteros
  • Teclado de pago tipo datáfono, sin ambigüedad decimal
  • Cambio siempre exacto, sin errores de redondeo
  • Aviso visual si el pago no cubre el total

Contadores por ticket

Tres secciones (combinado, cerveza/refresco y agua) con botones + y − para ir sumando lo que pide cada cliente.

Teclado de cobro

Teclado numérico en pantalla para introducir el dinero entregado, con entrada estilo datáfono para máxima rapidez.

Cambio automático

Calcula al instante cuánto dinero de cambio hay que devolver, o avisa si el importe entregado no es suficiente.

Precios editables

Panel de ajustes para fijar el precio de cada tipo de ticket antes del evento, guardado en el propio dispositivo.

Limpiar para el siguiente

Un solo botón pone a cero contadores y pago para atender al siguiente cliente sin arrastrar datos del anterior.

Pensada para el móvil

Botones grandes, sin zoom accidental por toques rápidos y alto contraste para usarla cómodamente al aire libre.
