Sobre el proyecto

Inventario IES Lacimurga es una aplicación web de inventario desarrollada de manera desinteresada para mi antiguo instituto IES Lacimurga. Permite gestionar el material deportivo y educativo del centro, con búsqueda por categorías, control de stock por tallas y exportación a Excel.

El proyecto está alojado en una organización de GitHub creada específicamente para el instituto, con GitHub Pages como hosting. Actualmente contiene datos de muestra, a la espera de incorporar el inventario real del centro.

Características principales

Categorías dinámicas

Sidebar con categorías y subcategorías desplegables para filtrar materiales por tipo.

Búsqueda inteligente

Normalización de tildes y caracteres especiales para búsquedas precisas en tiempo real.

Tabla avanzada

Paginación, ordenación por columnas y filtros combinados para gestión eficiente.

Inventario por tallas

Detalle de cada material con control de stock individual por talla (XS a XXL).

Exportación Excel

Descarga del inventario filtrado en formato .xlsx para gestión externa del centro.

Diseño responsive

Menú hamburguesa y adaptación completa para tablets y móviles.
