App Tickets

Gestión de incidencias con sistema de tickets de soporte

Proyecto finalizado
Android Java XML DAM

Sobre el proyecto

TICKETS es una aplicación móvil para la gestión de incidencias mediante tickets de soporte. Desarrollada durante las asignaturas de Desarrollo de Interfaces y Programación de Dispositivos Multimedia del segundo año de DAM, como proyecto práctico para consolidar conceptos de desarrollo Android nativo.

La app permite crear, editar y consultar tickets con título, descripción, pasos para reproducir el problema y estado del ticket. Incluye un listado dinámico con filtros por estado y un sistema de persistencia en archivos locales dentro del almacenamiento interno de la app.

Un aspecto clave del diseño fue la accesibilidad visual: los colores de los estados fueron seleccionados específicamente para ser distinguibles por personas con daltonismo, siguiendo pautas de contraste y percepción.

Sistema de estados (accesible)

Cada ticket puede tener uno de cinco estados, representados con colores cuidadosamente seleccionados para garantizar la distinguibilidad incluso para personas con daltonismo:

Crear Tickets

Formulario completo con título, descripción, pasos para reproducir y asignación automática de estado "Nuevo" e ID incremental.

Editar Existentes

Al tocar un ticket del listado, se abre el formulario pre-relleno permitiendo modificar cualquier campo y cambiar el estado.

Filtrado por Estado

Chips interactivos en la parte superior permiten filtrar el listado dinámicamente por cualquier combinación de estados.

Accesibilidad Visual

Paleta de colores seleccionada según pautas de percepción para daltonismo, asegurando distinguibilidad entre todos los estados.
