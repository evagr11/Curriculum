Sobre el proyecto

iMirly es mi Trabajo de Fin de Ciclo de DAM en New Digital Talent (Granada): un marketplace que conecta a personas que necesitan un servicio (reformas, limpieza, clases, estética...) con profesionales de su zona. Todo el proceso ocurre dentro de la app: se habla por chat, se negocia un presupuesto, el pago queda retenido en un monedero virtual y, al terminar, cliente y profesional se valoran.

Lo hicimos entre cuatro, sin jefe: cada uno asumía lo que mejor se le daba y las decisiones se tomaban en equipo. Además de la app Android y su backend, el proyecto tiene una demo web que se prueba sin instalar nada, una web de presentación, una web de documentación técnica y un manual de usuario.

Proceso de diseño

La app

MVP web

Para que cualquiera pudiera probar iMirly sin compilar la app, hice una versión web que recrea sus pantallas y flujos: onboarding, registro, catálogo con buscador, chat con presupuestos, favoritos, publicación de anuncios y monedero. Es una web estática (no usa el backend real) y en escritorio se muestra dentro de un marco de móvil.

Stack Tecnológico

App Android

  • Kotlin + Jetpack Compose
  • MVVM, ViewModels y corrutinas
  • Retrofit + OkHttp
  • Material Design 3

Backend

  • Java 17 + Spring Boot 3
  • Spring Security + JWT
  • PostgreSQL, H2 y JPA/Hibernate
  • Docker Compose

Webs y diseño

  • React + TypeScript + Vite + Tailwind
  • HTML, CSS y JavaScript
  • GitHub Pages
  • Figma y Canva
