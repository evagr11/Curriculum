Sobre el proyecto

Sama Vintage es un sitio web estático de ecommerce para una tienda de joyería vintage. El proyecto surgió como parte del módulo SGE (Sistemas de Gestión Empresarial) del segundo curso de DAM, donde el objetivo era realizar el rebranding completo de una web real existente.

Inicialmente se desarrolló en WordPress con WooCommerce, utilizando plugins como Code Snippets, Contact Form 7 y Simple Custom CSS. Posteriormente, reconstruí el proyecto desde cero como sitio estático en HTML, CSS y JavaScript vanilla, eliminando dependencias de CMS para crear una versión portable y mantenible como portfolio.

Evolución del proyecto

Fase 1: WordPress

Versión original desarrollada en equipo con WooCommerce, plugins personalizados y tema customizado. Proyecto académico colaborativo con compañeros de clase.

Proyecto en equipo

Fase 2: Sitio Estático

Reconstrucción completa en HTML/CSS/JS puro. Carrito persistente con localStorage, páginas dinámicas vía URL params y deploy en GitHub Pages.

Portfolio personal

Catálogo de Productos

Visualización de 50+ piezas de joyería organizadas por categorías: broches, pendientes y collares.

Páginas Dinámicas

Vista detallada de producto reutilizable mediante parámetros ?id= en la URL.

Carrito Persistente

Añadir, eliminar y actualizar productos con persistencia en localStorage entre sesiones.

Diseño Responsive

Navegación adaptable con menú responsive controlado por JavaScript. Compatible con todos los dispositivos.
