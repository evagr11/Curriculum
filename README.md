# 🚀 Sobre el Proyecto

Este proyecto es el **portfolio personal y curriculum web** de Eva Gallardo, una Desarrolladora de Aplicaciones Multiplataforma (DAM). Es un sitio estático construido desde cero con HTML semántico, CSS modular y JavaScript puro para crear una experiencia de usuario limpia, rápida y visualmente atractiva donde muestra sus habilidades y proyectos.

<div align="center">
  <img src="https://github.com/user-attachments/assets/5c97d927-6ad8-4aba-95de-6dd0d8559459" alt="Inicio de la pagina web de curriculum" width="80%"/>
  <p><em>Inicio de la pagina web de curriculum</em></p>
</div>

✨ **Características principales:**

*   🎨 **Diseño Moderno:** Interfaz limpia y elegante con un layout asimétrico que guía al usuario a través de las diferentes secciones.
*   📱 **100% Responsive:** El diseño se adapta perfectamente a cualquier dispositivo, desde monitores de escritorio hasta teléfonos móviles.
*   📂 **Portfolio Interactivo:** Más de 20 proyectos (Android, Unity, web, backend, escritorio y apuntes) con tarjetas visuales, filtros por tipo y una página de detalle para cada uno.
*   🏗️ **CSS Modular:** La hoja de estilos está organizada en módulos (sidebar, responsive, estilos principales) para facilitar el mantenimiento y la escalabilidad del código.
*   💨 **Navegación Fluida:** Transiciones suaves y una estructura de navegación intuitiva que mejora la experiencia de usuario al moverse entre las distintas páginas del sitio.

# 🧠 Contexto del Proyecto

Este es un **proyecto personal** creado con el objetivo de servir como carta de presentación profesional. Nació como una forma de aplicar y demostrar los conocimientos en desarrollo front-end, diseño de interfaces y organización de código, consolidando en un único lugar la trayectoria académica, habilidades y portfolio de proyectos de la autora.

# 📂 Estructura del Proyecto

La estructura del proyecto está organizada de forma modular para separar las distintas responsabilidades y facilitar su mantenimiento.

```bash
Curriculum/
├── assets
│   ├── cv/          # CV en PDF
│   ├── fonts/       # Font Awesome
│   ├── icons/
│   ├── img/         # Mockups y capturas de cada proyecto
│   └── pdf/         # Documentación de los proyectos
├── css
│   ├── reset.css
│   ├── estilos.css
│   ├── proyecto.css     # Estilos comunes de las páginas de proyecto
│   ├── responsive.css
│   └── sidebar.css
├── js
│   ├── maps.js
│   └── menu.js
├── proyectos/       # Una página de detalle por proyecto
│   ├── imirly-android.html
│   ├── simcra.html
│   ├── el-extremeno.html
│   └── ...
├── contacto.html
├── curriculum.html
├── index.html
├── portfolio.html
└── sobremi.html
```

# 🚀 Cómo Utilizar el Proyecto

Al ser un proyecto web estático, no requiere un proceso de construcción (build) ni dependencias complejas.

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/evagr11/Curriculum.git
    ```
2.  **Navega al directorio:**
    ```bash
    cd Curriculum
    ```
3.  **Abre el archivo principal:**
    Simplemente abre el archivo `index.html` en tu navegador web preferido.
    ```bash
    # En Windows
    start index.html
    
    # En macOS
    open index.html
    
    # En Linux
    xdg-open index.html
    ```

¡Y eso es todo! Ya puedes explorar el portfolio localmente.
